What this tab is — read this first
This is a build backlog, not a live dashboard section. Sleepycat.in has a mattress quiz, pillow quiz, EMI calculator, and pincode checker already live — none fire analytics events today. Every card below is one thing to instrument, why it matters, and what question it answers once live.
1. Quiz completion → conversion
Fire quiz_started, quiz_completed, quiz_recommendation_shown, quiz_recommendation_purchased. Strongest proxy for "considered purchase" intent you can build cheaply.
2. On-site search term logging
Log every search query and whether it returned zero results. You asked what people search for once on the site — this is the only way to answer that; channel-level source data (GA4 tab) tells you how they arrived, not what they typed once here.
3. Pincode serviceability check
Track pincode_checked with result. If PDP visitors are hitting "not serviceable," that's a silent conversion killer with zero current visibility.
4. Size/variant toggle behaviour
Track which size gets selected pre-ATC and whether visitors toggle between sizes (indecision signal). Cross with size distribution below.

What "recovery" means on this page: Someone adds items to cart and reaches checkout on Shopify (a "checkout started" record is created), but doesn't complete payment — that's an abandoned cart. Detection algorithm

For CVR, Orders, Revenue, and AOV: take the trailing 30 days (excluding the day being checked), compute the mean and standard deviation. For each of the most recent 10 days, compute z = (value − mean) ÷ standard deviation. |z| ≥ 2.0 = High (statistically unusual — less than ~5% chance this is normal variation). |z| ≥ 1.2 = Medium (worth a glance). Below that = normal day-to-day noise, not shown.
